# LOUCORD

LOUCORD é um projeto de estudos criado com o objetivo de aprimorar habilidades técnicas e de design no ecossistema React + Vite.<br/>
O repositório conta com um projeto inspirado na plataforma de comunicação Discord.

## Dependências

Desenvolvido com as seguintes tecnologias:

- **[Vite](https://vite.dev)** – ^7.2.4
- **[React](https://react.dev)** – ^19.2.0
- **[TypeScript](https://www.typescriptlang.org)** – ^5.9.x
- **[Tailwind CSS](https://tailwindcss.com)** – ^4.x

## Objetivo

- Usar websokects para uma comunicação de baixa latência
- Desenvolver uma aplicação lisa (funcional) e visualmente agradável
- Sistemas de chats, com upload de imagens e gifs
